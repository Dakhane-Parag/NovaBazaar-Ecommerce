# Notification Service

Handles email and in-app notifications.

## Responsibilities (future)

- Consume notification events from Kafka
- Send email notifications
- Store in-app notifications
- Support 5 event types: payment successful, payment failed, order confirmed, order shipped, order delivered

## Data Store

- PostgreSQL (notification_db)

## Status

Stair 0: Skeleton only. Notification functionality will be implemented in later stairs.
