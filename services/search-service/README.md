# Search Service

Provides product search capabilities.

## Responsibilities (future)

- Full-text search
- Fuzzy search with typo tolerance
- Autocomplete and suggestions
- Filtering (category, brand, price range, rating)
- Sorting and relevance ranking

## Data Store

- Elasticsearch (product index) — search index only, not source of truth
